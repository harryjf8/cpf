# CPF | CoPy File
Copy file contents directly to your clipboard

## Install:

Prerequisites:

- <a href="https://bun.sh/">bun</a>

`bun.sh build cpf.js --compile --outfile cpf`

## Usage:

`cpf <file to copy>`

- This program is useful for copying error log files to clipboard for debugging.
